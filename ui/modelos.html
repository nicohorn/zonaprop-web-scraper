¿Qué responde cada modelo?
A · Precio¿Cuánto debería valer este aviso? Para estimar precio justo / USD/m².
A2 · Ablación¿Qué variante del modelo de precio conviene? Compara variantes con CV sobre train (todas siguen seleccionables en A).
B · Oportunidades¿Qué avisos parecen baratos o raros? Para encontrar posibles gangas y errores de datos.
C · Renta vs. venta¿Dónde conviene más alquilar respecto del precio de compra? Por barrio, con el dólar MEP actualizado.
D · Segmentos¿Qué tipos de propiedades hay? Para estudiar submercados.
E · Texto¿Qué palabras del aviso mueven el precio? Para ver señales en las descripciones.
F · Tiempo hasta baja¿Cuánto tarda un aviso en desaparecer? Requiere re-scrapes con seguimiento de cambios.
¿Cuál uso?
  1. Empezá por A: te dice si el modelo de precio es confiable.
  2. Después B: usa la misma lógica para marcar gangas y errores.
  3. C cuando ya haya avisos de alquiler (y con el MEP del día).
  4. D para explorar el mercado sin una pregunta puntual.
  5. E cuando haya descripciones (mejor con fichas visitadas).
  6. F más adelante, tras varias pasadas con historial de cambios.
